## Featured project

### [FINWISE Engineering Showcase](https://github.com/YOUR-GITHUB-USERNAME/finwise-engineering-showcase)

A production financial planning platform that I designed, built, secured, tested, and deployed as a solo engineer. The showcase repository documents:

- **Architecture:** a browser-side calculation model that keeps visitor financial inputs off the server, with a small Node.js and Express backend and SQLite storage.
- **Security:** parameterized queries, output escaping, secret handling, cookie based sessions, and rate limiting, with the real bugs I found and fixed along the way.
- **Deployment:** domain registration at Namecheap, DNS at Cloudflare, a DigitalOcean server in Toronto behind Nginx and PM2, a Let's Encrypt certificate, Google Workspace mail, and Resend for transactional email, with screenshots as evidence.
- **Testing:** Playwright end to end suites and independent checks of numeric results.

Live product: https://www.strategicfinancialbuilding.ca
